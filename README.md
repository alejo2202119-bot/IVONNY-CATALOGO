# Catálogo digital IVONNY

Catálogo digital con buscador, carrito, modo edición y pedido por WhatsApp.

- `index.html` — portada de bienvenida.
- `catalogo.html` — catálogo de productos.
- `assets/banner.svg` — imagen principal (banner). Reemplázala por la imagen real de la empresa cuando esté disponible.

## Modo edición

En el catálogo, toca el punto (●) al final de la página, escribe la clave de edición y podrás:

- Marcar productos como Disponible / Agotado.
- Editar nombre, precio y foto.
- Agregar o eliminar productos.
- Descargar el catálogo actualizado (botón "Descargar") para volver a subirlo.

## Publicación

El sitio se publica automáticamente con GitHub Pages a partir de esta rama.
